# 🗣️ Kalki AI – Multilingual Voice Assistant

**Double‑click and talk.**  
Kalki AI is a voice‑controlled assistant that speaks **15+ Indian languages** and answers anything using Google Gemini.

---

## 🚀 For End Users (No coding required)

### Download & Run
1. Download `KalkiAI.exe` from the release page.
2. Place it in any folder (no installation needed).
3. **First run only:**  
   A console window will open and ask for your **Gemini API key**.
   - Get a free key from [Google AI Studio](https://aistudio.google.com/apikey)
   - Paste the key and press Enter.
4. The key is saved locally in `kalki_key.txt` – you will **never be asked again**.
5. Double‑click `KalkiAI.exe` again – it will start listening immediately.

### Commands
- Say **"goodbye"**, **"exit"**, **"bye"**, or **"बंद"** to quit.
- Just ask anything – Kalki understands and responds in your language.
